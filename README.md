# City Boutique Hotel Sarajevo — website concept

A multi-page website concept for a boutique hotel in Sarajevo's old town, focused on photography, motion design and a direct booking enquiry flow. Built as an unsolicited design proposal; not the hotel's official site.

**Demo:** [city-boutique-hotel.vercel.app](https://city-boutique-hotel.vercel.app)

## What's inside

- Pages for rooms, facilities, experiences, gallery, about, contact and booking
- Booking and general enquiry API routes
- Motion system with GSAP and Framer Motion: entrance sequence, scroll reveals, micro-interactions and a site preloader

## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · GSAP · Framer Motion · date-fns

## Running locally

```bash
npm install
npm run dev     # http://localhost:3000
```
